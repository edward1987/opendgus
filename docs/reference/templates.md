# Templates

Every template is responsive and is tested at 1024x600, 800x480, 480x272 and 480x800.

| Template | Pages | Description |
|---|---|---|
| `access_control`: Access control | Ready, Granted, Denied, Admin PIN | Card-reader door terminal: 'present your card' idle screen with clock and door state, access granted and denied screens switched by the MCU, and an admin PIN keypad. |
| `alarm_panel`: Alarm panel | Status, Zones, Keypad | Security panel with armed/disarmed status, arm away/home and disarm, an eight-zone status grid and a code keypad. |
| `car_dashboard`: Car dashboard | Cluster, Trip | Instrument cluster with a big speed readout inside an RPM arc, fuel and coolant bars, gear, turn signals and warning lights, plus a trip computer. |
| `coffee_machine`: Coffee machine | Drinks, Options, Brewing, Care | Bean-to-cup coffee machine: eight-drink selection grid, strength slider, cup size and extra shot, a brewing progress screen and water/beans/grounds care status. |
| `elevator_panel`: Elevator panel | Car, Emergency, Out of service | Elevator car panel: large floor number with up/down/idle arrow and door status, a floor-button grid, door open/close, alarm bell, an emergency-call screen and an out-of-service screen. |
| `ev_charger`: EV charger | Charge, Live, Settings | Wallbox charging screen: battery ring, charging power, energy, session cost and time, start/stop, cable/plug state, live electrical values and charging settings. |
| `greenhouse`: Greenhouse | Climate, Devices, Rules | Greenhouse controller: air temperature, humidity and soil moisture gauges, light and CO2, pump/fan/grow-light/heater toggles with auto mode, and threshold sliders for the automation. |
| `home_control`: Home control | Devices, Climate | Six device toggles and a climate page with setpoint, temperature, humidity and heating. |
| `industrial_hmi`: Industrial HMI | Overview, Process, Alarms | Machine operator panel: running/stopped/fault status, start/stop/reset, line-speed slider, production counters, temperature/pressure/load/vibration gauges and an alarm list with acknowledge. |
| `music_player`: Music player | Now playing, Library, Sound | Now playing with transport, progress, volume, shuffle and repeat; sources and playlists; bass/mid/treble sound page. |
| `order_kiosk`: Order kiosk | Burgers, Pizza, Drinks, Checkout | Self-order kiosk: category tabs, product grid with +/- quantity buttons, live cart total and a checkout page with eat-in/take-away and payment choice. |
| `pin_keypad`: Smart lock keypad | Unlock, Settings | PIN entry with a 3x4 keypad, masked PIN dots and lock state, plus an auto-lock settings page. |
| `printer_3d`: 3D printer | Print, Temps, Move | FDM printer panel: progress ring with layer count and times, hotend and bed temperatures (current/target), pause/stop and part fan, temperature presets and an XYZ jog page. |
| `queue_display`: Queue display | Now serving, Staff | Public 'now serving' screen with a big ticket number per counter, the next ticket and people waiting, plus a staff page to call, recall or skip tickets. |
| `settings_pages`: Settings pages | Display, Network, Date & time, About | Generic device settings: brightness and volume sliders, Wi-Fi status and switches, date and time with +/- buttons, and an about page with firmware version, restart and factory reset. |
| `solar_monitor`: Solar monitor | Flow, Battery, Today | Solar + battery system monitor: live power flow between PV, battery, house and grid, battery ring with backup reserve, daily energy totals and inverter/grid/battery status. |
| `status_dashboard`: Status dashboard | Status, Details | Generic status tiles with an editable controller message, display clock, and QR code. |
| `thermostat`: Thermostat | Home, Schedule, Settings | Room thermostat: big setpoint with +/- buttons, indoor temperature and humidity, heat/cool/off mode, a four-period weekday schedule and comfort settings. |
| `universal_panel`: Universal panel | Overview, Controls | General reading and state overview with a progress bar, mode choice, and setpoint slider. |
| `vitals_monitor`: Vitals monitor (demo) | Monitor, Limits | Clinical-style vitals display for demos and prototypes (not for diagnosis): heart rate, SpO2, blood pressure, temperature and respiration in colour-coded tiles, alarm status and limits. |
| `washing_machine`: Washing machine | Programs, Options, Status | Program selection grid, temperature and spin choices, extras, and a status page with remaining time, progress ring, wash phase and door lock. |
| `weather_station`: Weather station | Now, Forecast, Details | Weather station: condition icon, temperature with feels-like and high/low, humidity, pressure, wind speed and direction, rain, a 5-day forecast and sunrise/sunset/UV/indoor details. |
