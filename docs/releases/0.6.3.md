# OpenDGUS 0.6.3

This release expands the visual editor and opens more of the DGUS toolset to everyday projects.

## What's new

- Add live text, clock, QR code, choice, and live curve controls.
- Add a universal control panel and a status dashboard, bringing the template gallery to 22 designs.
- Save selected items as reusable presets within a project.
- Clone and edit controller board profiles for additional hardware.
- Import backgrounds and compatible compiled controls from DGUS V7.651 projects. The importer reports items that need manual review.
- Show estimated flash use during validation, render QR codes in the emulator, and give the AI designer clearer validation and emulator guidance.
- Add a versioned widget plugin entry point for Python packages.

## Testers and contributors wanted

Some functions may not work as expected, especially on display and controller hardware we have not tested. **We need testers.** Please feel free to try this release and [open an issue](https://github.com/edward1987/opendgus/issues/new) with the display model, board, steps to reproduce, and what happened. Reports about successful hardware tests are welcome too.

If you want to contribute to the project, [open an issue](https://github.com/edward1987/opendgus/issues/new) describing how you would like to help, and we will discuss it there.
